# PyQt6 Calculator

A PyQt6 calculator project built to explore desktop GUI development, including layouts, widgets, signals and slots, and event-driven programming.

## Features

- Basic arithmetic operations
- Number and operator input
- Decimal input
- Delete functionality
- AC button for clearing the current calculation
- ANS button for recalling the previous answer during the current session
- Error handling for invalid calculations

## Technologies

- Python
- PyQt6

## Project Goals

This project was built to gain practical experience with:

- Desktop GUI development
- PyQt6 layouts and widgets
- Signals and slots
- Event-driven programming
- Managing application state
- Connecting user interactions to application logic
